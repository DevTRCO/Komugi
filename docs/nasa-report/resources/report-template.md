# NASA Report Template

Use this template for generating reports at `docs/nasa-report/NASA-REPORT-{YYYY-MM-DD}-{scope-slug}.md`.

## Template

```markdown
# NASA Assessment Report

**Date:** {YYYY-MM-DD}
**Scope:** {description of what was assessed}
**Assessor:** Claude (NASA Skill v1.0)
**Overall Status:** {NOMINAL | CAUTION | WARNING | CRITICAL | ABORT}

---

## Executive Summary

{2-3 sentences describing overall health, most critical finding, and recommended action}

---

## Counterfactual: Without This Assessment

{Describe what would have happened if this review was NOT performed. Be specific:}

- **Most dangerous undetected issue:** {description}
- **Estimated time to discovery:** {days/weeks/months}
- **Probable trigger:** {What event would surface the issue?}
- **Impact on discovery:** {What damage would have occurred by the time it was found?}
- **Cost to fix post-incident vs now:** {Multiplier estimate: 5x? 10x? 50x?}

---

## Dimension Scores

| Dimension        | Grade   | Findings | Critical | Actions Required |

| 4. Scalability   | {grade} | {count}  | {count}  | {summary}        |
```

## Report Naming Convention

Format: `NASA-REPORT-{YYYY-MM-DD}-{scope-slug}.md`

Examples:

- `NASA-REPORT-2026-02-17-screenshot-capture.md`
- `NASA-REPORT-2026-02-17-gemini-integration.md`
- `NASA-REPORT-2026-02-17-full-system.md`
- `NASA-REPORT-2026-02-17-mini-chat.md`

## Report Storage

All reports go to: `docs/nasa-report/`

Create the directory if it doesn't exist. Previous reports are preserved for historical tracking.
